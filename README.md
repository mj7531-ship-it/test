# 낙서 걸음마

손가락으로 아무거나 그리면, 그 그림이 말랑한 젤리 몸이 되어 스스로 걷는 법을 배우는 페이지.

`index.html` 하나를 브라우저로 열면 끝. 외부 라이브러리, 이미지 생성, AI 모델 호출 없이 전부 이 파일 안에서 돌아가.

- 오른쪽 아래 해/달 버튼으로 라이트·다크 모드를 바꿀 수 있어. 고른 모드는 기기·Claude 테마 설정보다 우선하고, 다음에 열어도 유지돼.
- 그림은 브라우저에 자동 저장돼서 다시 열면 이어서 그릴 수 있어. 저장은 그 브라우저 안에만 남아(`localStorage`). 시크릿 창에서는 저장되지 않아.
- **진화 기록판**: 큰 진화가 일어난 세대만 적어. 새 걸음 발견(기록도 10%·0.15m 이상 늘었을 때), 한 세대 만의 큰 도약(0.4m 이상이면서 30% 이상), 1·3·5·10m 같은 거리 첫 돌파야. 기록판을 보는 동안 경주는 멈춰.
- **세대 비교**: 1세대, 고른 세대, 최신 세대 챔피언이 세 줄에서 동시에 달려. 가운데 줄은 슬라이더, ‹ ›, 큰 진화 세대 버튼으로 고르거나 기록판의 "비교"로 바로 열 수 있어.
- **진화 저장**: 진화 전체(세대별 챔피언 유전자, 현재 개체군, 난수 상태)와 기록판이 브라우저에 저장돼. 다시 열면 그 세대부터 이어서 달리고, 비교도 그대로 돼. 몸은 처음 태어난 획 그대로 다시 만들어서, 옛 세대 챔피언도 기록과 똑같이 움직여. "다시 그리기"를 눌렀다면 그리기 화면의 "이어서 진화"로 돌아갈 수 있어. 저장은 "살아나라!"나 "새로 진화"로 새로 시작할 때만 바뀌어.
- **챔피언 저장**: 최신 챔피언을 1080×1350 PNG 카드로 만들어. 세대·걸음, 마지막 몇 초의 잔상(반 몸길이 간격), 최고 기록, 1세대 대비 배율, 큰 진화 횟수, 세대별 최고 기록 그래프가 들어가. claude.ai 뷰어에서는 `downloads` 기능으로 저장을 요청하고(뷰어가 확인), 오프라인 파일이나 일반 웹에서는 바로 내려받아. 어느 쪽이든 미리보기 이미지를 길게 누르거나 오른쪽 클릭해서 저장할 수도 있어.

## 오프라인 버전

`offline.html`은 폰트까지 파일 안에 넣은 버전이야. 인터넷 없이 열어도 손글씨 폰트까지 그대로 보여. 페이지에 실제로 쓰인 글자만 남겨서 약 365KB야.

폰트나 페이지를 고친 뒤 다시 만들려면:

```sh
pip install fonttools brotli
python3 tools/build_offline.py
```

넣은 폰트는 Gaegu, IBM Plex Sans KR, IBM Plex Mono(SIL OFL 1.1)를 필요한 글자만 남겨 줄인 버전이야. OFL 규칙(IBM Plex의 예약 폰트 이름 "Plex")에 맞춰 `Nakseo Hand / Sans / Mono`로 이름을 바꿨고, 라이선스 전문은 `offline.html` 머리에 들어 있어.

## 어떻게 움직여?

1. **몸 만들기** — 획을 격자에 래스터화하고 닫힌 영역을 채워. 거리장으로 얇은 부분을 찾아 두께를 보정하고, 떨어진 조각은 최단 경로로 이어 붙인 뒤 삼각 격자로 점(질량)과 스프링을 만들어. 원래 획은 삼각형 무게중심 좌표로 몸에 묶여서 같이 찌그러져.
2. **근육** — 몸을 k-means로 4~10덩어리로 나누고, 덩어리마다 사인파 리듬(진폭·위상)으로 스프링 길이를 바꿔. 몸 전체 주파수까지 합쳐 `2K+1`개의 숫자가 유전자야.
3. **물리** — XPBD 질량-스프링 soft body, 60Hz × 서브스텝 8. 바닥은 관통 깊이로 수직항력을 근사한 쿨롱 마찰.
4. **진화** — 개체 30마리가 8초 동안 달리고, 오른쪽으로 간 거리가 점수. 엘리트 4 + 1등 미세 변이 6 + 무작위 이민 1 + 토너먼트 선택·균등 교차·가우시안 변이.
5. **재현** — 시뮬레이션이 결정론적이라 같은 유전자는 언제 다시 돌려도 똑같이 움직여. 그래서 1세대 챔피언과 지금 챔피언을 나란히 다시 달리게 할 수 있어.
