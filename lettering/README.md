# 한글 레터링 시트 — 추석 / 할인 / 주유 / 연휴

2048×2048, 순흑 배경에 순백 글자, 2×2 그리드로 네 단어를 조판한 시트.

```
추석   할인
주유   연휴
```

## 왜 이미지 생성이 아니라 조판인가

요구사항이 자간·자평·획 굵기·자음의 위치별 변형·모음 삐침을 네 단어에서
똑같이 맞추는 것이었다. 확산 모델로 글자를 그리면 매번 획 굵기와 자소 위치가
새로 뽑혀서 이걸 맞출 수 없고, 한글 철자가 깨질 위험도 있다.

반대로 한 벌의 폰트로 조판하면 같은 설계의 자소를 같은 크기·같은 피치로
찍는 것이라 위 다섯 가지가 구조적으로 보장된다. 그래서 조판으로 갔다.

## 시안

**기본** — 폰트를 그대로 조판한 것. 세 폰트 × 자평 110 / 120.

| 키 | 폰트 | 톤 |
|---|---|---|
| `hahmlet` | Hahmlet Bold (700) | 고대비 모던 레트로 |
| `nanum` | 나눔명조 ExtraBold (800) | 정통 견출명조 |
| `songmyung` | 송명 | 옛 활판, 가는 획 |

**후처리** (`refined_*`) — 함렛에 윤곽선 후처리를 얹은 것. 자평 120 / 125 / 130.

## 무엇이 맞춰져 있나

한 시트 안에서:

- **글자 높이** — 여덟 음절 전체의 잉크 높이를 재서 `LETTER_HEIGHT` 에 맞춘다
- **베이스라인** — 네 단어가 같은 기준선에 앉는다
- **획 굵기** — 같은 폰트를 같은 크기로 쓰므로 동일
- **자간** — 음절 피치가 상수라 두 음절 사이 간격이 네 단어 모두 같다
- **전체 폭** — 피치와 자폭이 상수라 네 단어의 폭이 정확히 같다
- **자소 변형·삐침** — 폰트가 설계한 한 벌을 그대로 쓴다

시안 사이에서도 글자 높이를 같은 값으로 정규화하므로, 세 시안을 나란히 놓고
자평 차이만 비교할 수 있다. 열과 행은 바깥 여백과 가운데 여백이 같아지는
지점에서 자동으로 잡으므로 글자 크기나 자평을 바꿔도 배치가 균형을 유지한다.

## 윤곽선 후처리 (`refine.py`)

폰트가 그려준 윤곽선의 점을 옮기는 방식이다. 원본 폰트 파일은 건드리지 않는다.

| 연산 | 하는 일 |
|---|---|
| `contrast` | 세로 기둥을 양옆으로 불리고 가로획을 위아래로 깎아 획 대비를 키운다 |
| `sharpen` | 볼록하고 날카로운 모서리만 골라 바깥으로 더 내민다. 쐐기 세리프와 삐침이 살아난다 |
| `oval` | 둥근 속공간을 가로로 좁혀 세로 타원으로 만든다. ㅇ 과 ㅎ 의 동그라미가 대상이다 |

방향은 각 점의 법선에서 뽑는다. 법선의 x 성분이 큰 점(세로획의 옆면)만 x 로
밀리고 y 성분이 큰 점(가로획의 위아래면)만 y 로 당겨지므로, 사선 획은 두
성분이 섞여 자연스럽게 중간값을 받는다.

법선은 윤곽선이 감싼 영역의 바깥을 가리킨다. 바깥 윤곽선에서는 그 방향이
글자를 살찌우지만 구멍에서는 구멍을 키우므로, 구멍에서는 부호를 뒤집어야
획이 두꺼워진다. `hole_flags()` 가 자기보다 큰 윤곽선에 몇 겹 둘러싸였는지
세서 이걸 판정한다.

함렛 120 기준 실측:

| | ㅇ 속공간 w/h | 세로획 | 가로획 | 획 대비 |
|---|---|---|---|---|
| 기본 | 0.90 | 63px | 30px | 2.1 : 1 |
| 후처리 | 0.68 | 73px | 24px | 3.0 : 1 |

## 산출물

```
out/lettering_<시안>_<자평>.png   기본 시안 6장, 2048x2048
out/lettering_<시안>_<자평>.svg   같은 기하의 벡터
out/refined_hahmlet_<자평>.png    후처리 시안 3장
out/refined_hahmlet_<자평>.svg
out/_contact_base.png             기본 6장 비교 시트
out/_contact_refined.png          후처리 3장 비교 시트
```

SVG 가 원본이고 PNG 는 그 SVG 를 cairosvg 로 래스터화한 결과라 둘의 기하는
완전히 같다. 더 손보고 싶으면 SVG 를 일러스트레이터에서 열면 된다.

## 실행

```bash
pip install Pillow fonttools cairosvg
python3 generate.py
```

폰트는 `fonts/` 에 들어 있다. 다시 받으려면 `./fetch_fonts.sh`.

## 조정할 만한 값

`generate.py` 상단:

- `LETTER_HEIGHT` — 글자 높이(px). 키우면 여백이 줄어든다
- `INK_GAP` — 음절 사이 간격. 글자 높이 대비 비율. 작을수록 붙는다
- `COL_TIGHTEN` / `ROW_TIGHTEN` — 1.0 이 균형점. 낮추면 열/행이 가운데로 모인다
- `REFINE` — 후처리 강도. 길이는 전부 em 단위라 글자 크기와 무관하게 비율이 유지된다
- `VARIANTS` — 뽑을 시안 목록
- `WORDS` — 다른 단어로 바꿔도 된다. 두 음절이면 그대로 동작한다
